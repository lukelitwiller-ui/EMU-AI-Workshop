Build a reminder system from a spreadsheet

You have a list of people who each need to submit something, at different stages. This exercise shows you how you could build a reminder system to generate your email drafts directly in Gmail with dynamic copy.

Start here

Seven steps

  1. Make your copy of the sheet using the button above. It lands in your own Drive, already filled in. Do not build a sheet yourself.
  2. Open gemini.google.com in a new tab.
  3. Copy the prompt below and paste it into Gemini.
  4. Copy the code Gemini gives back.
  5. In your sheet, go to Extensions › Apps Script. Click the project name at the top left and rename it Reminder machine. You will see that name again in a moment, and it matters.
  6. Delete everything in the editor, paste the code, and save.
  7. Go back to the sheet and reload the page. A new menu appears. Click it.

You need a laptop for this one. The Extensions menu does not exist in the Sheets mobile app. If you are on a phone, pair up with someone who brought one.

Step three

The prompt

Do not retype this. Hit copy.

Paste this into Gemini 
I use a Google Sheet to track students who each need to complete a requirement. I want a Google Apps Script that decides who needs a reminder and writes the emails for me.

The sheet has one tab called Roster with these columns in this order: Name, Email, Item needed, Status, Due date, Reminders sent, Last reminder. Row 1 is headers. Status is one of Not started, Started, or Complete. Reminders sent is a number. Last reminder is a date or blank.

Here is a sample row so you can see the shape:
Avery Nolan | avery.nolan@example.com | Immunization record | Not started | 2026-08-01 | 0 | (blank)

Go through every row and apply these rules:
- If Status is Complete, skip the row.
- If the due date has not passed, skip the row.
- If past due and Reminders sent is 0, create a first reminder.
- If past due and Reminders sent is 1 and Last reminder was 7 or more days ago, create a second, firmer reminder.
- If past due and Reminders sent is 2 and Last reminder was 7 or more days ago, do not write an email. Add the person to a tab called Needs a call instead.

The emails should be short and warm, address the person by first name, name the specific item they owe, and mention the due date.

Important requirements:
- Create Gmail drafts. Do not send anything.
- After drafting, increase Reminders sent by one and put today's date in Last reminder.
- Add a menu to the spreadsheet called Reminders with one item that runs this.
- When it finishes, show me a popup summarizing how many first reminders, second reminders, and calls came out of the run.
- Add comments explaining what each section does, because I don't write code.

You never showed Gemini a single real person. It saw column names, one invented row, and your rules. The code came back, and the code runs where your data already lives.

Step seven

The permission screen

Everyone hits this. Nothing has gone wrong. Two screens stand between you and a working script.

First screen: "Authorization required"

It offers Cancel and Review permissions. Cancel is drawn like the safe button. It is not the one you want. Click Review permissions and confirm your EMU account.

Second screen: the permission grant

It names your script and lists what it wants access to. Check every box, or click Select all, then continue. A partial grant fails later in a way that looks like broken code.

Read that screen before you click. One line says "Read, compose, send, and permanently delete all your email from Gmail." That should get your attention. Three things are true about it:

  • The app asking is yours. Look at the name on that screen. It says Reminder machine, because you typed that a minute ago. The thing requesting access to all your email is the code you pasted ninety seconds ago.
  • The ask is broad because it has to be. Apps Script requests Gmail access at the account level. There is no drafts-only permission to grant.
  • You can take it back. Go to myaccount.google.com/permissions any time and revoke it in about four clicks.

Troubleshooting

If nothing happens

  • No new menu? Reload the sheet, and check that you saved in the Apps Script editor.
  • Wrong people getting emails? Check that the column order matches what you told Gemini.
  • Nothing at all, and no error? Almost always a date problem. Sheets dates and script dates do not compare cleanly, and it fails silently.
  • Still stuck? Raise a hand. A flagged failure is worth more to this room than a quiet success.

Round two

Make it yours

Pick one. They get harder as you go down.

Change the voice

Rewrite the second reminder in your own tone, or add a third one.

Add an owner

Add a column for the office that owns each item, and sign the email from that office.

One digest instead

Send yourself a single daily summary of everyone overdue, rather than individual drafts.

Different item, different message

Write a distinct message depending on which item is missing.

Keep a log

Add a Log tab that records every draft it ever creates, with a timestamp.

Run it without you

Make it fire on its own every Monday morning. This one needs a trigger. Go find it.

Take it with you

Before you leave

What is the list you actually chase at work? Incomplete files, missing forms, unsigned documents, overdue trainings, unreturned equipment. It is the same shape as what you just built.
